## Android Enrollment Setup

This guide is based on the following setup:

- The IT department keeps the QR code and enrolls devices. End users should not do this themselves.
- Intune is configured so that all Android devices and all users can enroll an Android device.
- App assignments are configured for all users.
- Android supports different launchers. In this example, Microsoft Launcher is used.

## Device Requirements

Find a mobile phone or tablet with at least the following Android version:

| Enrollment type | Minimum Android version |
| --- | --- |
| Android Enterprise (Work Profile / general) | 8.0+ |
| Fully Managed / Corporate-owned | 10.0+ |

## License Requirements

Microsoft Intune Plan 1 is required. This is included in Microsoft Developer subscriptions.

## Connect a Managed Google Play Account

1. Go to Intune.
2. Open **Devices > Android > Enrollment > Managed Google Play**.
3. Select **Connect to Google now**.
4. Sign in with a Microsoft account or Gmail account.
5. When the confirmation message appears, continue to the next step.

## Share a Wallpaper Image

Intune requires a URL that points to a wallpaper image. One option is to upload the wallpaper to SharePoint and share it publicly. The steps below describe how to publish a wallpaper image through SharePoint.

1. Enable **Anyone** sharing at the tenant level.
   - A SharePoint administrator should go to **SharePoint admin center > Policies > Sharing**.
   - Under **External sharing**, set SharePoint sharing to **Anyone**.

2. Enable **Anyone** sharing for the relevant site.
   - Go to **SharePoint admin center > Sites > Active sites**.
   - Select the site where the image is stored.
   - Open **Settings**, then **More sharing settings**, and choose **Anyone**.
   - Save the change.

3. Upload the wallpaper image.
   - Upload the JPG or PNG file to a document library on that site.

4. Create a sharing link for the image.
   - Select the image file.
   - Select **Share** and choose an **Anyone** link.
   - Choose **View only** if that option is available.

5. Copy the link.
   - Copy the sharing link generated by SharePoint.

6. Test the link.
   - Open the link in an InPrivate or Incognito window where you are not signed in.
   - If you are asked to sign in, the link will not work for Microsoft Launcher wallpaper deployment.

- Assign the profile to all users.
- Assign the profile to all devices.

## Create a Compliance Policy

1. Go to **Devices > Android > Compliance policies**.
2. Require users to use a device passcode.
3. Assign the policy to **All devices** for initial testing.

## Deploy Apps

1. Confirm that Microsoft Launcher has already been assigned.
2. Go to **Intune > Apps > Android > Create**.
3. Choose **Managed Google Play app**.
4. Add an app such as Outlook.
5. Select and sync the app.
6. Assign it to **All devices** to test the function.
7. After testing, create dynamic groups for Android mobile devices if needed.
8. Make sure the apps are actually assigned.
9. If you are not using dynamic Android groups yet, you can assign apps to **All devices** during testing.

## Functional Test

On the phone or tablet:

1. Start with a new or factory-reset device.
2. Tap the screen seven times during the initial setup.
3. A prompt to scan the QR code should appear.
4. Scan the enrollment QR code and continue the setup.
